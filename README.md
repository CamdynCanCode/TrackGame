# TrackGame

A career-focused track & field sports game inspired by games like EA Sports and NBA 2K.

## Vision

TrackGame aims to make track & field feel like a full sports-game experience rather than just a collection of races.

The player creates an athlete, competes in meets, improves their abilities, builds a reputation, signs with brands, and eventually works toward a professional career.

## Core Experience

* Create and customize an athlete
* Compete in track & field events
* Race against AI competitors
* Train and develop abilities
* Set personal records
* Compete in increasingly important meets
* Build a reputation
* Sign sponsorship contracts
* Customize equipment and clothing
* Progress through a career

## Initial MVP

The first playable version will focus on one thing: making an 800m race fun.

The MVP target is:

* One track
* 800m event
* Playable athlete
* AI competitors
* Basic race simulation
* Stamina/fatigue
* Race timer
* Finish detection
* Results screen
* Basic athlete progression
* Basic character customization

Everything beyond this is secondary until the core race is working.
